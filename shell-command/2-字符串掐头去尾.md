# 字符串掐头去尾

在Linux Shell中，"掐头去尾" 通常指从字符串或文本中移除开头和结尾的部分。有多种方法来实现，本文做一个基础总结。


## 1. 字符串处理（适用于变量）

### 1.1 使用 `${var#pattern}` 和 `${var%pattern}`

```bash
# 1. 掐头（移除开头匹配的部分）
str="prefix_content_suffix"
echo "${str#prefix_}"                 # content_suffix
echo "${str#*_}"                      # content_suffix（贪婪匹配第一个_后的所有内容）

# 2. 去尾（移除结尾匹配的部分）
echo "${str%_suffix}"                 # prefix_content
echo "${str%_*}"                      # prefix_content（贪婪匹配最后一个_前的内容）

# 3. 掐头去尾（同时操作）
str="prefix_middle_suffix"
result="${str#prefix_}"
result="${result%_suffix}"
echo "$result"                        # middle
```

### 1.2 使用 `${var##pattern}` 和 `${var%%pattern}`（贪婪匹配）

```bash
# 1. 贪婪掐头（移除最长匹配的前缀）
str="dir1/dir2/file.txt"
echo "${str##*/}"                    # file.txt（类似 basename）
echo "${str##*.}"                    # txt（获取扩展名）

# 2. 贪婪去尾（移除最长匹配的后缀）
echo "${str%%/*}"                    # dir1（类似 dirname 的第一部分）
echo "${str%%.*}"                    # dir1/dir2/file（移除扩展名）

# 3. 示例：获取文件名和扩展名
file="image.2023.jpg"
filename="${file%.*}"                # image.2023
extension="${file##*.}"              # jpg
basename="${file##*/}"               # 如果是完整路径
```
