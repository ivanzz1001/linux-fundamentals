# 字符串掐头去尾

在Linux Shell中，"掐头去尾" 通常指从字符串或文本中移除开头和结尾的部分。有多种方法来实现，本文做一个基础总结。


## 1. 字符串处理（适用于变量）

### 1.1 使用 `${var#pattern}` 和 `${var%pattern}`

```bash
# 1. 掐头（移除开头匹配的部分）
str="prefix_content_suffix"
echo "${str#prefix_}"                 # content_suffix
echo "${str#*_}"                      # content_suffix（贪婪匹配第一个_后的所有内容）

# 2. 去尾（移除结尾匹配的部分）
echo "${str%_suffix}"                 # prefix_content
echo "${str%_*}"                      # prefix_content（贪婪匹配最后一个_前的内容）

# 3. 掐头去尾（同时操作）
str="prefix_middle_suffix"
result="${str#prefix_}"
result="${result%_suffix}"
echo "$result"                        # middle
```

### 1.2 使用 `${var##pattern}` 和 `${var%%pattern}`（贪婪匹配）

```bash
# 1. 贪婪掐头（移除最长匹配的前缀）
str="dir1/dir2/file.txt"
echo "${str##*/}"                    # file.txt（类似 basename）
echo "${str##*.}"                    # txt（获取扩展名）

# 2. 贪婪去尾（移除最长匹配的后缀）
echo "${str%%/*}"                    # dir1（类似 dirname 的第一部分）
echo "${str%%.*}"                    # dir1/dir2/file（移除扩展名）

# 3. 示例：获取文件名和扩展名
file="image.2023.jpg"
filename="${file%.*}"                # image.2023
extension="${file##*.}"              # jpg
basename="${file##*/}"               # 如果是完整路径
```

## 2. 使用cut命令

### 2.1 按字符位置
```bash
# 1. 掐头（移除前N个字符）
echo "1234567890" | cut -c 4-              # 4567890（从第4个字符开始）
echo "1234567890" | cut -c 6-              # 67890（从第6个字符开始）

# 2. 去尾（保留前N个字符）
echo "1234567890" | cut -c -7              # 1234567（保留前7个字符）
echo "1234567890" | cut -c -5              # 12345（保留前5个字符）

# 3. 掐头去尾（取中间部分）
echo "1234567890" | cut -c 3-7             # 34567（第3到第7个字符）
echo "1234567890" | cut -c 4-8             # 45678

# 4. 指定多个字段（从结尾开始算）
echo "1234567890" | rev | cut -c 3- | rev  # 移除最后2个字符：12345678
```

### 2.2 按分隔符
```bash
# 1. 掐头（移除前N个字段）
echo "a,b,c,d,e,f" | cut -d ',' -f 4-     # d,e,f（从第4个字段开始）
echo "a:b:c:d:e" | cut -d ':' -f 3-       # c:d:e

# 2. 去尾（保留前N个字段）
echo "a,b,c,d,e,f" | cut -d ',' -f 1-3    # a,b,c（前3个字段）
echo "a:b:c:d:e" | cut -d ':' -f 1-2      # a:b

# 3. 掐头去尾（取中间字段）
echo "a,b,c,d,e,f" | cut -d ',' -f 2-4    # b,c,d（第2到第4字段）

# 4. 选择特定字段
echo "a,b,c,d,e" | cut -d ',' -f 1,3,5   # a,c,e（第1,3,5字段）
```

## 3. 使用awk命令

### 3.1 按位置处理
```bash
# 1. 掐头（移除前N个字符）
echo "1234567890" | awk '{print substr($0, 4)}'                # 4567890
echo "1234567890" | awk '{print substr($0, 6)}'                # 67890

# 2. 去尾（保留前N个字符）
echo "1234567890" | awk '{print substr($0, 1, 7)}'             # 1234567
echo "1234567890" | awk '{print substr($0, 1, 5)}'             # 12345

# 3. 掐头去尾（取子串）
echo "1234567890" | awk '{print substr($0, 3, 5)}'             # 34567（从第3个字符开始取5个）
echo "1234567890" | awk '{print substr($0, 4, 3)}'             # 456

# 4. 从结尾开始
echo "1234567890" | awk '{print substr($0, length($0)-3)}'     # 最后4个字符：7890
echo "1234567890" | awk '{print substr($0, 1, length($0)-2)}'  # 移除最后2个字符：12345678
```

### 3.2 按分隔符处理
```bash
# 1. 掐头（移除前N个字段）
echo "a,b,c,d,e,f" | awk -F ',' '{for(i=4;i<=NF;i++) printf "%s%s", $i, (i==NF?"\n":",")}'
# 输出：d,e,f

# 2. 去尾（保留前N个字段）
echo "a,b,c,d,e,f" | awk -F ',' '{for(i=1;i<=3;i++) printf "%s%s", $i, (i==3?"\n":",")}'
# 输出：a,b,c

# 3. 更简洁的方法（使用OFS）
echo "a,b,c,d,e,f" | awk -F ',' -v OFS=',' '{print $4,$5,$6}'   # d,e,f
echo "a,b,c,d,e,f" | awk -F ',' -v OFS=',' '{print $1,$2,$3}'   # a,b,c

# 4. 取中间字段
echo "a,b,c,d,e,f" | awk -F ',' -v OFS=',' '{print $2,$3,$4}'   # b,c,d
```

## 4. 使用sed命令

### 4.1 正则表达式匹配

```bash
# 1. 掐头（移除开头的模式）
echo "prefix_content_suffix" | sed 's/^prefix_//'              # content_suffix
echo "1234567890" | sed 's/^...//'                             # 4567890（移除前3个字符）
echo "1234567890" | sed 's/^.\{5\}//'                          # 67890（移除前5个字符）

# 2. 去尾（移除结尾的模式）
echo "prefix_content_suffix" | sed 's/_suffix$//'              # prefix_content
echo "1234567890" | sed 's/...$//'                             # 1234567（移除最后3个字符）
echo "1234567890" | sed 's/.\{4\}$//'                          # 123456（移除最后4个字符）

# 3. 掐头去尾（同时操作）
echo "prefix_middle_suffix" | sed 's/^prefix_//;s/_suffix$//'  # middle
echo "1234567890" | sed 's/^.\{2\}//;s/.\{3\}$//'              # 34567（移除前2个和后3个）

# 4. 使用分组提取
echo "prefix_middle_suffix" | sed 's/^prefix_\(.*\)_suffix$/\1/'  # middle
echo "abc123def" | sed 's/^abc\(.*\)def$/\1/'                     # 123
```

## 5. 使用`grep`和`grep -o`
```bash
# 1. 提取匹配的部分
echo "The price is $99.99" | grep -o '[0-9.]*'              # 99.99
echo "Error 404: Not Found" | grep -o '[0-9]*'              # 404

# 2. 提取两个标记之间的内容
echo "start_middle_end" | grep -o 'start_.*_end'            # start_middle_end
echo "start_middle_end" | sed 's/start_\(.*\)_end/\1/'      # middle

# 3. 使用 Perl 正则（更强大）
echo "data: value=1234" | grep -oP 'value=\K\d+'            # 1234
echo "id: 56789, name: test" | grep -oP 'id: \K[0-9]+'      # 56789
```

## 6. 使用rev命令反向处理

```bash
# 1. 移除最后N个字符（通过反转处理）
str="1234567890"
echo "$str" | rev | cut -c 3- | rev                          # 12345678（移除最后2个字符）
echo "$str" | rev | cut -c 5- | rev                          # 123456（移除最后4个字符）

# 2. 移除开头N个字符（通过反转）
echo "$str" | rev | cut -c 1-7 | rev                         # 4567890（移除前3个字符）

# 3. 取最后N个字符
echo "$str" | rev | cut -c -3 | rev                          # 890（最后3个字符）
```
